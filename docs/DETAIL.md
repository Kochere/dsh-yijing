# 易占 · 金钱卦

为所问之事起一卦，并把《周易》经文原样交到智能体手里。

## 做什么

`yijing_cast` 收下用户的问题，用金钱起卦法连摇六爻：

- 三枚铜钱，背为阳三、字为阴二；
- 三背老阳（九）、三字老阴（六）、一背二字少阳（七）、二背一字少阴（八）；
- 老阳老阴为动爻，动爻翻转得之卦；
- 依动爻数，按朱子《易学启蒙·考变占》取出应当参看的卦辞或爻辞。

`yijing_hexagram` 可按序号、卦名、全称、卦符或六位阴阳码查任意一卦的经传原文，用于查看之卦、互卦、错卦、综卦。

## 返回什么

只有古文原文：

- 本卦与变卦的卦辞、彖、大象；
- 所主之爻辞与小象；
- 用九、用六（乾、坤六爻全变时）；
- 互卦、错卦、综卦的卦名。

没有白话翻译，没有后世注疏。解卦由智能体完成：点明卦象与动爻，引所主之辞，**先给古文、再用白话讲清**，然后就所问立断。用户不必读得懂文言。

## 看得见

起卦后，回答开头（解卦之前）会出现一张动画卦卡：三枚铜钱翻转，六爻自初爻至上爻依次画出，随后本卦、之卦落款；左侧动爻以“动”标出。实心小钱为背、空心为字。卡面随明暗主题自适应，尊重“减少动态效果”的系统设置，也可以“重演”。普通对话不会出现这张卡。

## 怎么用

直接问即可，例如“这个方案可行吗？”“这次合作能否成？”智能体先确认问题，再起卦、取辞、解卦。

命令行也可复核：

```bash
node bin/yijing.mjs cast "此次合作能否谈成？"
node bin/yijing.mjs cast --values 7,8,9,6,7,8 "复核一卦"
```

## 经文

64 卦、384 爻、用九用六、乾坤文言俱全，只存古文。爻辞逐条与《御纂周易折中》武英殿刊本（1715）转录对校，共 58 处订正；彖、象与第二来源互校。详见包内 `docs/SOURCES.md`。

## 局限

- 起卦使用本机加密随机数，不可复现；需要复核时用 `--values` 指定六爻。
- 只做《周易》经占，不含纳甲、六亲、世应、神煞等六爻排盘。
- 六爻全变时乾坤占用九用六，本于朱子；历代有异说，此处不展开。
- 占断是对处境的读解与劝诫，不是对事实的预言。

## 配置

- `prompt`：是否注入起卦与解卦的系统提示，默认 `true`。
- `maxQuestion`：所问之事的最大字数，默认 `300`。
