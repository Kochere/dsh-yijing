# 经文来源与校勘

《周易》经文为公有领域古籍。本插件的经文数据由 `scripts/build-data.mjs` 从下列转录重建，运行时只读 `lib/hexagrams.json`。

## 采用底本

| 用途 | 来源 | 说明 |
| --- | --- | --- |
| 基础文本（简体、标点） | [Classical-Chinese-Text-Dataset · wangxb96](https://github.com/wangxb96/Classical-Chinese-Text-Dataset) `data/yijing_V2.1.json` | 64 卦的卦辞、彖、大象、爻辞、小象，简体标点。作为底本。 |
| 爻辞校勘 | [《御纂周易折中》武英殿刊本（1715）爻辞转录](https://zenodo.org/records/23298982) | 384 爻及用九用六，繁体无标点，逐爻有哈佛燕京图书馆藏本影像复核记录。用于订正底本。 |
| 彖、象、文言互校 | [open-iching · john-walks-slow](https://github.com/john-walks-slow/open-iching) `ichuan/tuan.json`、`xiang.json`、`wen.json` | 用作第二来源，专订底本彖、象中的讹字。 |
| 卦辞、异文参照 | [zhouyi.cc 六十四卦原文](https://www.zhouyi.cc/zhouyi/yijing64/)（经 [liujuntao123/yijing](https://github.com/liujuntao123/yijing) 整理） | 仅作第三方参照，未直接取用其白话部分。 |

三枚铜钱之法、动爻翻转为之卦，属通行方法；取辞用朱子《易学启蒙·考变占》，见 [《性理大全书》本](https://www.shidianguji.com/mid-page/7430194564226433076)。

## 校勘方法

1. 以基础文本为底，逐爻与《折中》武英殿本比对。比对前统一去标点、转简体；《折中》为繁体，用静态字表转换（只 236 字，见 `scripts/t2s.json`），避免自动转换误伤“乾”等字。
2. 凡底本与《折中》实质不同者，以《折中》为准订正；彖、象则以底本与 open-iching 互校，择善而从。
3. 每一条订正都写死“旧文”，构建时若旧文不匹配即报错，避免静默漂移。
4. 构建后重跑全量比对：384 爻及用九用六逐条过一遍，余下差异必须能归入异体字或已知异文。

当前结果：**58 处订正**；对校后仅余两处异文（见下）；数据完整性检查 0 警告。

## 主要订正

底本有三类问题：错简、讹字、异体。代表性的订正：

- **大有六二**：底本误作“同人于宗，吝”（同人六二之文），正为“大车以载，有攸往，无咎”。
- **姤九五**：底本“以杞包瓜，含章，有陨自天”整句重复，去重。
- **复初九**：底本“不复远”，正为“不远复”。
- **大过九五**：底本“老妇得士夫”，正为“老妇得其士夫”。
- **蒙六三**：底本“勿用娶女”，正为“勿用取女”。
- **震大象**：底本“虩雷，震；君子以恐惧修身”，正为“洊雷，震；君子以恐惧修省”。
- **乾彖**：底本“大明始终”，正为“大明终始”。
- **坎彖**：底本“坎之时用大矣哉”，正为“险之时用大矣哉”。
- **大过彖**：底本“大过之时义大矣哉”，正为“大过之时大矣哉”。
- **履大象**：底本“安民志”，正为“定民志”。
- **晋九四**：底本“晋如硕鼠”，正为“晋如鼫鼠”。

完整列表见 `scripts/build-data.mjs` 的 `OVERRIDES` 表（每条含卦序、字段、旧文、新文）。

## 存异

对校后仍存两处，属版本异文，非讹字：

| 位置 | 本插件 | 《折中》 | 说明 |
| --- | --- | --- | --- |
| 革六二 | 己日乃革之 | 已日乃革之 | 卦辞“己日乃孚”从通行本作“己”；《折中》作“已”。 |
| 中孚初九 | 有它不燕 | 有他不燕 | “它/他”通用；比初六从《折中》作“它”，此处统一作“它”。 |

另有一些异体字按通行简体处理，不计入异文：彚→汇、闚→窥、朶→朵、薰→熏；古籍字形如“乾”“繻”“餗”“纆”“撝”保持正体，以免生僻简化字影响阅读。
